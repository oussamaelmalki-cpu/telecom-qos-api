# 🚀 Telecom QoS API (FastAPI + Docker + Cloud)

API de prédiction de la dégradation de la QoS (5G) déployée sur le Cloud avec Docker et FastAPI.

👉 **Testez l'API en direct ici :** https://telecom-qos-api-4d914.containers.snapdeploy.app/docs

## 🛠️ Stack Technique
- **Machine Learning :** Scikit-Learn (Random Forest)
- **API :** FastAPI
- **Conteneurisation :** Docker
- **Cloud :** SnapDeploy
